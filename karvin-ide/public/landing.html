WHAT YOU CAN DO

The tools you need.
The control you keep.

Work in the editor, run commands, and review agent actions in the same workspace.

⌘

Edit your whole project

Browse folders and change files with a familiar VS Code editor. Cline is installed in the sidebar when you need a coding partner.

›_

Use a real terminal

Install dependencies, start development servers, and run your checks. Preview apps through the editor’s port proxy.

⇄

Plan before you act

Inspect and discuss the approach in Plan mode. Switch to Act when you are ready to make changes.

✓

Review agent actions

Mission Control pauses file edits and project commands for your approval, with activity and results visible as the task runs.

✳

Choose your model

Connect your preferred provider in Cline. Mission Control also supports a configured OpenAI-compatible model endpoint.

⌁

Extend Cline with MCP

Use the installed Cline extension’s MCP settings to connect the tools and services your project needs.

◎

Run browser missions

Give a browser agent a starting URL and a goal. Follow its activity and inspect the evidence when a configured model is available.

↗

Keep your work

Commit your changes with Git or export Mission Control projects as ZIP files. Pick up your work again in your Codespace.
